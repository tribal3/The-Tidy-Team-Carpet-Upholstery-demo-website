# The Tidy Team — website concept

A single-page website concept for The Tidy Team, a carpet and upholstery cleaning business based in Billesley, Birmingham.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Stack

React, TypeScript, Vite, Tailwind CSS v4, Lucide React.

## Notes

- Business facts, review quotes and image provenance are documented in [RESEARCH.md](./RESEARCH.md).
- The enquiry form is a front-end demonstration only. It validates input and shows a success state, but does not send data anywhere. The phone number is the real contact route.
- All photographs in `public/images/tidy-team/` were supplied by the business via its public Google Maps profile. No stock photography is used.
- The site uses British English throughout.
